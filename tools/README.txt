# ANPR/OCR Library for Ukrainian and European License Plates

## Overview

Набор скриптиов предназначена для автоматического распознавания автомобильных номерных знаков на изображениях. Процесс состоит из двух этапов:

1. Детектирование номерного знака на фотографии автомобиля (YOLO).
2. Распознавание текста номерного знака (CRNN OCR).

Поддерживаются украинские и европейские номерные знаки.

---

## Project Structure

### Detection Model

**best.onnx**

ONNX-модель детектора номерных знаков, обученная на базе YOLO.

Назначение:

* поиск номерных знаков на изображении автомобиля;
* выдача координат найденных рамок;
* подготовка изображений для OCR.

---

### OCR Models

#### crnn_ua_100.onnx

Модель распознавания украинских номерных знаков.

Особенности:

* обучена на украинских регистрационных номерах;
* использует фиксированный набор символов (ALPHABET);
* оптимизирована для работы в реальном времени.

#### crnn_eu_20.onnx

Модель распознавания европейских номерных знаков.

Особенности:

* поддержка различных форматов номерных знаков стран Европы;
* совместима с тем же механизмом OCR.

---

## Recognition Functions

### runFolder()

Распознавание номерных знаков на фотографиях автомобилей.

Алгоритм работы:

1. Загрузка изображения.
2. Поиск номерных знаков с помощью `best.onnx`.
3. Вырезание найденных областей.
4. Передача вырезанных изображений в OCR.
5. Вывод распознанного текста.

Вход:

* папка с изображениями автомобилей.

Выход:

* список найденных номерных знаков.

---

### runOCRFolder()

Распознавание текста на уже вырезанных изображениях номерных знаков.

Используется для:

* тестирования OCR;
* оценки качества модели распознавания;
* подготовки статистики ошибок.

Вход:

* папка с изображениями номерных знаков.

Выход:

* распознанный текст для каждого изображения.

# OCR Training Pipeline

## 1. Dataset Preparation

### build_labels.py

Формирование обучающих данных для OCR.

Вход:

* изображения номерных знаков;
* JSON-файлы с разметкой.

Выход:

* файл `labels.txt`.

Формат:

filename.jpg TEXT

Пример:

00001.jpg AA1234BC

---

## 2. Character Filtering

### split_dataset.py

Подготовка датасета для обучения украинской OCR-модели.

Назначение:

* фильтрация кириллических символов;
* приведение данных к набору символов ALPHABET;
* разделение выборки на обучающую и тестовую части.

---

## 3. OCR Training

### train_ua_ocr_new.py

Основной скрипт обучения CRNN.

Настраиваемые параметры:

* количество эпох;
* размер изображения;
* размер батча;
* скорость обучения;
* архитектура модели.

### Transfer Learning

В разделе `MODEL` присутствует закомментированный блок загрузки весов.

При его активации возможно:

* продолжение обучения существующей модели;
* дообучение на новых данных;
* перенос обучения на другой тип номерных знаков.

Результат обучения:

* файл модели `.pth`.

---

## 4. ONNX Export

### ocr_convert.py

Конвертация обученной модели из формата PyTorch (`.pth`) в формат ONNX (`.onnx`).

Используется для:

* запуска на Windows/Linux без PyTorch;
* интеграции в C++ приложения;
* ускоренного инференса.

---

# Important Note

Во всех этапах подготовки данных, обучения и инференса необходимо использовать одинаковое значение `ALPHABET`.

Изменение порядка символов или состава ALPHABET между обучением и распознаванием приведёт к некорректной работе OCR-модели.
